# Как выложить RingooStroy на хостинг Beget

Домен: **ringoostroy.ru**  
Что выкладываем: только фронтенд (папка `dist` после сборки). База и Django не нужны.

---

## Что уже подготовлено в проекте

- Сборка отдаёт готовый сайт в папку `frontend/dist`
- Файл `.htaccess` лежит в `public/` и попадает в `dist` — из‑за него прямые ссылки работают:
  - `https://ringoostroy.ru/about`
  - `https://ringoostroy.ru/equipment`
  - `https://ringoostroy.ru/equipment/sany-sy35u`
  - и остальные страницы
- HTTPS и редирект `www` → без www
- SEO, sitemap и robots уже на домен `https://ringoostroy.ru`

---

## Шаг 1. Собрать сайт на своём компьютере

1. Открой папку проекта `frontend` в терминале (PowerShell или CMD).

```bash
cd c:\ringo-stroy-temp\frontend
```

2. Поставь зависимости (один раз или после обновлений):

```bash
npm install
```

3. Собери продакшен-версию:

```bash
npm run build
```

4. Проверь, что появилась папка `dist`. Внутри должны быть примерно такие файлы:

- `index.html`
- `.htaccess`  ← важно, без него прямые URL сломаются
- `assets/` (js и css)
- `images/`
- `robots.txt`
- `sitemap.xml`
- `manifest.json`

Локально можно глянуть так:

```bash
npm run preview
```

Открой в браузере адрес из терминала и проверь несколько страниц с обновлением (F5) по прямой ссылке.

---

## Шаг 2. Зайти в панель Beget

1. Зайди на [https://cp.beget.com](https://cp.beget.com)
2. Открой раздел с сайтами / доменами
3. Найди сайт для **ringoostroy.ru**
4. Запомни папку сайта — обычно это что-то вроде:

`ringoostroy.ru/public_html`

Именно сюда нужно залить содержимое `dist` (не саму папку `dist`, а то, что **внутри** неё).

---

## Шаг 3. Привязать домен (если ещё не привязан)

В панели Beget:

1. Добавь домен `ringoostroy.ru` (и при желании `www.ringoostroy.ru`)
2. В DNS домена должны стоять NS-серверы Beget  
   (их пишет сама панель, обычно `ns1.beget.com` / `ns2.beget.com` и т.п.)
3. Если домен был на Vercel — в регистраторе домена смени NS/DNS на Beget и подожди обновление DNS (от нескольких минут до суток)

---

## Шаг 4. Залить файлы

### Вариант А — через файловый менеджер Beget

1. Открой «Файловый менеджер»
2. Зайди в `public_html` своего домена
3. Удали старые файлы сайта (если там что-то было), **кроме** служебных папок Beget, если они есть
4. Залей **всё содержимое** папки `dist`:
   - `index.html`
   - `.htaccess`
   - папки `assets`, `images`, `videos` и остальные файлы

Важно: после загрузки в корне `public_html` сразу лежит `index.html`, а не папка `dist`.

### Вариант Б — через FTP (FileZilla и т.п.)

1. В панели Beget возьми FTP-логин, пароль и хост
2. Подключись
3. Залей содержимое `dist` в `public_html`

---

## Шаг 5. Включить HTTPS (SSL)

1. В панели Beget открой SSL / Let’s Encrypt для `ringoostroy.ru`
2. Выпусти бесплатный сертификат
3. Включи принудительный HTTPS (если есть такая галочка)

`.htaccess` тоже переводит HTTP → HTTPS, но сертификат в панели всё равно нужен.

---

## Шаг 6. Проверить, что всё открывается

Открой в браузере и обнови страницу (F5 / Ctrl+F5):

1. https://ringoostroy.ru/
2. https://ringoostroy.ru/about
3. https://ringoostroy.ru/contacts
4. https://ringoostroy.ru/equipment
5. https://ringoostroy.ru/equipment?cat=instrumenty
6. Любую карточку техники, например из каталога
7. https://ringoostroy.ru/services
8. https://www.ringoostroy.ru/ — должен перекинуть на версию без www

Если прямая ссылка даёт 404, а с главной по меню открывается — почти всегда нет `.htaccess` в корне или Apache его не читает. Проверь, что файл на месте и называется именно `.htaccess`.

---

## Как обновлять сайт потом

1. На компьютере в `frontend`:

```bash
npm run build
```

2. Снова залей новое содержимое `dist` в `public_html` (можно перезаписать файлы)
3. Готово

Менять JSON с техникой/услугами, фото и тексты — тоже в проекте, потом снова `npm run build` и заливка `dist`.

---

## Частые проблемы

| Проблема | Что сделать |
|---|---|
| 404 на `/about`, `/equipment` | Проверь, что в `public_html` есть `.htaccess` |
| Белый экран | Смотри консоль браузера (F12). Часто залили не содержимое `dist`, а папку целиком |
| Нет картинок | Проверь, что папка `images` уехала на хостинг |
| Сайт старый | Очисти кэш браузера / открой в режиме инкогнито |
| www и без www разные | Нужен редирект из `.htaccess` + DNS на оба имени |

---

## Коротко

1. `npm install`  
2. `npm run build`  
3. Содержимое `dist` → в `public_html` на Beget  
4. SSL для ringoostroy.ru  
5. Проверить прямые ссылки на страницы  

После этого сайт работает полностью на хостинге, без базы и без бэкенда.
